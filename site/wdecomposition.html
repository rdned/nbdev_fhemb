Wdecomposition API

Wdecomposition encapsulates the wavelet‑based decomposition of an Embedding, exposing each frequency‑band subsignal as its own Embedding and providing methods for their analysis and recombination.

The Method Resolution Order (MRO)

the exact linear path Python follows when looking up attributes or when super() is invoked.

Wdecomposition
 └── ValidateSubjsMixin
      └── ValidateFbandsMixin
           └── object

Architectural responsibilities

  • Frequency‑domain bridge: decompose an Embedding into band‑limited components and map each band to a band‑specific Embedding.

  • Metadata and caching: record metadata about the wavelet family and decomposition level, numeric frequency and period ranges, and cache reconstructions to avoid recomputation.

  • Loop closer: produce new Embedding objects by reconstructing embeddings from selected bands (so the pipeline can iterate: Embedding → Wdecomposition → Embedding → …). Wdecomposition is transient — it enables multiresolution analysis but the Embedding remains the canonical product the system analyzes.

The Constructor


def Wdecomposition(
    decomposed_embedding:Embedding, # Dict['subject', np.ndarray['feature', 'time' ]]
    fband_embedding:dict, # A dictionary mapping frequency bands to their corresponding embeddings.
    features:tuple[int, ...] | None=None, # The features to be used in the decomposition, by default None (which means all features).
    wavelet:str='db2', # The type of wavelet to use for decomposition, by default "db2".
    level:int=8, # The number of decomposition levels, by default 8.
):

Class for handling wavelet decomposition of signals. This class manages the wavelet decomposition of signals, allowing for reconstruction of signals based on selected frequency bands and subjects. It provides methods for creating reconstructed embeddings and caching results

Creating Another Embedding

create_wreconstruction(subjs, fbands) → Embedding

Reconstructs an embedding from a selected set of frequency bands.

  • If fbands is empty → returns the original decomposed embedding
  • Otherwise → returns a reconstruction using only the specified bands
  • In both cases → projected to the requested subjects

    subjs:List, # Subjects to project the reconstruction for.
    fbands:List, # Frequency bands to include in reconstruction.
)->Embedding: # sort the subjects by default
frequency bands: by default "all" and sorted

Reconstruct signals for selected subjects and frequency bands.

Note

This method is decorated with @validate_fbands(bands="all", sort=True, allow_empty=False), so the default behavior for fbands (“all”, sorted) is automatically reflected
