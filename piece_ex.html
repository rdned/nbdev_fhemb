Specify the Piece object, which stores:

  • the opera title,
  • the time interval (as a frame range),
  • subject intervals, where each subject is associated with a tracked heatmap time series.
Exported source 
dg0 = Piece(              
    title='Don Giovanni',
    time_interval=(14200,15200), 
    subjs=[(40, 44), (47,52), 53, 54, (56, 71), (73, 75)]
)

Ask for an attribute

  • facebbox_t will be fetched from a DB
dg0.facebbox_t
<fhemb.dbms.db.Datasource>

Now the attribute is cached

dg0.api()
 ******* CLASS API *******
dict_keys(['facebbox_t'])
Note

facebbox_t is a Datasource object (fhemb.dbms.db.Datasource) used to access tracked face-bounding-box time-series data and derived embeddings. In this example, it contains 37 tracked time series of subjects \(\{40,..,76\}\) who enjoyed Don Giovanni opera. All the time series are restricted to the segment of \(1000\) frames in the specified interval \([14200, 15200)\).
