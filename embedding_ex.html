Create Complex Embeddings

by constructing an EmbeddingCollection object

There are two ways to build an EmbeddingCollection object, and they differ in how much you specify explicitly versus how much you delegate to the Datasource.

1. Direct construction using Embedding objects

In this route, you instantiate Embedding objects yourself and pass them to the EmbeddingCollection constructor. Each embedding is fully specified — you choose the subjects, the features, and the factory that produces them. This is the fully manual path and gives you complete control, even allowing you to combine embeddings from different datasources (though this is rarely needed in practice).

2. Using Datasource.projection (syntactic shorthand)

The second route is more concise. Instead of constructing Embedding objects directly, you ask the Datasource to project (Datasouirce.project) itself onto a set of features. The projection syntax automatically creates the corresponding embeddings behind the scenes. This approach is slightly less general but typically more convenient, since the datasource uses its own schema and defaults to derive the embeddings for you.

We demonstrate both: first constructing full embeddings, i.e., without using projection, then constructing the more general projected embeddings.

Full Embeddings

no features are projected out

Exported source 
from nbdev_fhemb.datasource_ex import dg0, pca
Exported source

    factory=pca                              # specify PCA factory to use for creating the PCA embedding (imported)

Datasource.project syntactic shorthand

Exported source 
combined_emb1 = dg0.face_t.project(                              # project all available features of the Datasource face_t to specified `features`
    features=[('pc0', 'pc4'), ('p0', 'p100'), ('bh0', 'bh18')],  # specify all features: none will be projected out
    pcfactory=pca,                                               # specify PCA for principle components 
)

Projected Embeddings

only selected features are included in the embedding

Exported source 
pca_emb_prj = pca_emb.project(         # project all available features of the Embedding pca_emb to specified `features`    
    subjs=[40],                        # specify subject(s) to project to: may be specified also as intervals, e.g., [(40, 45), 47]   
    features=[('pc0', 'pc2')],         # specify features to project to: principal components are prefixed by 'pc', specified as na interval
)

percentile_emb_prj = percentile_emb.project(   # project all available features of the Embedding percentile_emb to specified `features`  
    subjs=[40],  
    features=['p20', 'p80'],           # percentiles are prefixed by 'p'
)

bin_emb_prj = bin_emb.project(         # project all available features of the Embedding bin_emb to specified `features`     
    subjs=[40], 
    features=[('bh1', 'bh3')],         # bin heights are prefixed by 'bh': specified as an interval
)
